دخول الخزنة

خزنة ملاحظات خاصة — بياناتك لا يراها أحد سواك

مشروع تجريبي يعتمد على قاعدة بيانات Supabase مع تفعيل RLS (Row Level Security): كل مستخدم يسجّل دخوله برقم المستخدم الخاص به auth.uid()، وسياسات قاعدة البيانات تمنع ظهور أي ملاحظة لمستخدم آخر — حتى لو حاول أحدهم الاستعلام مباشرة من الواجهة البرمجية.

ابدأ الآن — تسجيل الدخول أو إنشاء حساب

1) تسجيل دخول آمن

حسابات حقيقية عبر Supabase Auth (بريد + كلمة مرور). الجلسة محفوظة محلياً بعد الموافقة فقط.

2) محتوى خاص لكل مستخدم

جدول notes يحفظ كل ملاحظة مع user_id تلقائياً من هوية المستخدم الحالي.

3) عزل على مستوى قاعدة البيانات

سياسات RLS: auth.uid() = user_id — العزل يتم داخل PostgreSQL نفسها وليس في الواجهة فقط.

4) زر فحص العزل

داخل الخزنة زر «افحص العزل» يحاول قراءة كل الصفوف وينبّهك إن ظهر أي صف لا يخصك.

لماذا Supabase؟

Supabase يعطيك قاعدة بيانات PostgreSQL حقيقية مع نظام هوية وRLS جاهزين، ويمكن ربطها من المتصفح مباشرة بمفتاح عام (anon key) فقط — دون وضع أي مفتاح سري في الكود.
